使用教程

StarVoice 星语 是一款浏览器侧边栏扩展:在小红书 / 抖音 / 微博的页面上一键采集作品、评论与博主数据,自动归集到云端后台(并可同步飞书),用于品牌舆情巡检与内容研究。

五步快速上手

  1. 安装并固定扩展
    安装后点浏览器右上角拼图图标,把「StarVoice 星语」固定到工具栏。点击图标即可在右侧打开侧边栏面板。
  2. 激活绑定
    在侧栏展开「产品授权状态」,输入客户经理提供的激活码(形如 OSV-A-XXXXXXXX),点「验证并绑定」。绑定成功后会显示所属客户、到期时间与环境绑定数。每个激活码可绑定固定数量的环境(浏览器),达上限可在验证时替换旧环境。
  3. (可选)配置数据同步
    若贵司使用飞书多维表,展开「数据同步配置」填入飞书 App Token 与表格信息,采集结果会同步进表。即使不配置飞书,数据也会进入云端后台,不影响使用。
  4. 到平台页面采集
    打开小红书 / 抖音 / 微博对应页面,侧栏会自动识别页面类型并切到对应标签(内容页 / 主页 / 搜索页),按提示点采集即可。三种采集方式见下。
  5. 查看数据
    采集的数据进入云端后台 voice.minilife.online/admin(用后台账号登录),在「舆情风控 / 内容创意」工作区查看分诊、看板与报告;若配置了飞书则同步到飞书表。

三种采集方式

① 内容页 —— 采单篇作品 + 评论。打开任意一条笔记 / 视频 / 微博的详情页,侧栏切到「内容页」,点采集即可拿到这篇的正文、点赞 / 收藏 / 评论 / 转发指标,以及评论区内容。

② 主页 —— 采某个博主的作品列表。打开博主 / 账号 / 用户主页,侧栏切到「主页」,可批量采集 TA 的作品。支持增量采集(自动跳过已采过的)与评论补采。

③ 搜索页 —— 按关键词批量采。在平台内搜索关键词后,侧栏切到「搜索页」,可按关键词批量采集结果。可设置点赞阈值(只采高于该热度的)、排序维度,并开启无人值守循环挂机连采。

评论与客资筛选

在「评论区客资筛选配置」中可设定识别规则,系统会对评论作者作疑似身份分级(如 4S 店 / 同行 KOE / KOL / 真实用户),并识别销售客资线索,便于在后台研判时一键剔除非真实车主、聚焦真实声音。

账号监控规则 / 对标监控

在「账号监控规则」中可登记需要持续关注的账号(自有号或竞品对标号),配合后台监控中心做定期巡检与对比。

采集偏好配置

在「采集偏好配置」中可调整增量采集、抖音号补采、采集条间隔等。条间隔用于控制采集节奏、降低被平台风控的概率,默认值已较稳妥,通常无需改动。

防风控小贴士:保持平台账号已登录;不要长时间高频连采;一旦页面弹出「安全验证 / 滑块」,请先停止采集、手动完成验证、稍候再继续。扩展已内置撞到风控即停的保护,但合理节奏仍是关键。

常见问题

支持哪些平台?
小红书、抖音、微博。在这三个平台的作品详情页、博主主页或搜索结果页打开侧栏即可采集。
激活码绑定数满了怎么办?
每个激活码限定可绑定的环境(浏览器)数量。达上限时,在「验证并绑定」过程中可选择替换某个旧环境;若确需更多席位,请联系我们扩容。
采集到的数据在哪里看?
统一进入云端后台 voice.minilife.online/admin,用后台账号登录后在「舆情风控 / 内容创意」工作区查看。若你在扩展里配置了飞书同步,则同时写入飞书多维表。
为什么有的作品评论数 / 点赞数显示 0?
个别页面的版式差异会导致某项计数没读到,此时会回落为 0,不影响正文与评论内容的采集。刷新页面后重新采集通常即可恢复。
采集时弹出「安全验证」或被限制?
这是平台的风控机制。请停止当前采集,在页面上手动完成验证(滑块 / 短信等),降低频率后再继续。扩展内置了「撞到风控即停」的保护以免越刷越严。
笔记 / 图文的评论采不全?
请确保页面已滚动到评论区并展开「查看全部评论」,评论较多时采集需要一定时间逐步加载。如仍异常,可刷新后重采。
扩展控制台里一直有一些报错,要紧吗?
大多是良性提示,不影响使用。例如 [SingleNote] Failed to extract … count 是个别计数没读到、[CaptureSync] DETAIL_CAPTURE_CANCELED 是你中途停止采集时的正常提示;此外浏览器还会记录所访问网站自身的 CSP 报错,与本扩展无关。如遇到明显影响功能的错误,请联系我们。
怎么更新到最新版?
点侧栏右上角菜单的「检查更新」查看版本;企业客户版由我们提供新的安装包,按提示重新加载扩展即可。更新内容见 更新日志。
数据安全与隔离怎么保证?
采用多租户体系,每家客户拥有独立空间、数据完全隔离,通过专属激活码与后台账号开通,互不可见。
遇到问题找谁?
采集、登录或激活码相关问题,欢迎随时通过 关于与联系 页的微信 / 邮箱 / 电话与我们联系,我们会尽快协助。
