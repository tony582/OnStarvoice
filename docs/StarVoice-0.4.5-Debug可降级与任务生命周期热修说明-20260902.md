# StarVoice 0.4.5 Debug 可降级与任务生命周期热修说明

日期：2026-09-02
分支：codex/hotfix-v045-debug-optional-20260902

## 事故结论

昨晚和今早的停滞并不是账号被封、安全验证或采集页面本身失败。根因是 Extension 把 AI Debug 辅助会话的启动、占用和断开错误地接入了主采集生命周期；辅助能力不可用时，任务可能被冷却、转交或停止。与此同时，任务结束与下一 attempt 启动存在并发清理竞态，旧任务可能清理新任务资源；值守页还展示了服务端无法证明的关闭、冷却和倒计时状态。

0.4.5 将 AI Debug 明确降级为“采集辅助”：没有 Debug 也必须继续页面采集。只有 BEGIN 所有权不确定且精确 END 也无法确认的极端情况才硬失败，以避免遗留未知浏览器资源。

## 修复内容

### Extension

- AI Debug 启动失败、被外部会话占用或运行中断开时，不取消任务、不冷却 Agent、不交回关键词、不返回首页，主采集继续。
- 调试会话、任务页、worker、原生标签组与运行锁均按 task、attempt、平台、来源页和 replacement lease 校验所有权。
- BEGIN 与 END 共用生命周期队列，旧 attempt 的 END 完成前不会启动新 attempt，旧清理不会删除新资源。
- BEGIN 响应丢失可精确重发；若 BEGIN 是否生效无法判断且 END 也无法确认，则返回 capture_task_begin_cleanup_failed，不伪装为可降级成功。
- MV3 service worker 休眠或重启后，只恢复当前精确 attempt；旧 attempt、已移动或已复用的标签页不会被复活或误删。
- 博主主页采集在列表、详情和最终清理全过程持有执行锁；结束后释放，允许继续领取下一任务。
- 抖音保持单 worker；小红书只有在 worker 可被完整跟踪时才使用双缓冲，否则退回单 worker，避免留下无人管理的标签页。

### Server

- 恢复命令只有仍在有效期内才作为 blocking_command；过期命令不再阻止或伪装当前恢复状态。
- Ops 运行时最低版本同步提升至 0.4.5。

### Admin / 值守

- 不再从兼容字段推断“已关闭”“原 Agent 冷却”或默认三次重试。
- 只有真实有效的恢复命令才显示下发或等待；过期、损坏或不存在的命令不再生成虚假倒计时。
- waitingForSourceClosure 仅保留历史兼容元数据，新快照不再产生对应告警或动作。

## 发布门禁

- 全量 Node 回归必须全部通过。
- PostgreSQL 集成必须在临时数据库全部通过，并在结束后清理测试数据库。
- Admin TypeScript、生产构建与变更面 ESLint 必须通过。
- Extension 生产快照、Chrome for Testing 浏览器生命周期回归、变更脚本语法和 git diff --check 必须通过。
- 0.4.5 ZIP 必须可解压，manifest 版本、生产 API、文件清单和 SHA-256 必须核对。

## 发布后验收

1. Chrome 与 Edge 各一个真实 Extension Profile 上报 0.4.5 心跳。
2. 抖音、小红书各完成一条真实关键词：领取、列表、详情、保存、同步、结算并继续领取。
3. AI Debug 被占用和运行中断开两种场景下，主采集继续，不冷却、不换 Agent、不回首页。
4. 强制 MV3 service worker 休眠/重启后，不复活旧 attempt、不重复标签组、不误关新 worker。
5. 博主主页列表与详情全过程只有一个执行锁，成功与失败路径都能释放。
6. 小红书真实搜索结果保存完整 xsec_token URL，并能从后台再次打开。
7. 连续两次 Ops 观察后，历史关闭证明告警应消失，不再产生新的虚假告警。

## 回滚边界

- 本次无数据库迁移，但发布前仍保留并验证 PostgreSQL 自定义格式备份。
- Server/Admin 使用同文件系统原子目录交换，保留上一版本目录；Extension 保留上一版本 ZIP 与 SHA-256。
- 客户浏览器更新完成前，服务端上线不代表客户端修复已生效；按 Profile 验证心跳后再计为客户端接受。

当前文件在提交和生产核验完成前仅代表 0.4.5 发布候选，不代表已经推送、合并、部署或客户设备验收。
