日期：2026-09-08。开发分支：`codex/hotfix-customer-daily-report-20260908`。

工作目录：`OnStarvoice-hotfix-customer-daily-report-20260908`。从已核实的线上服务提交 `fd74954427b9d83eec2e87429ad5e8e631562808` 建立独立 worktree；未把架构分支的未提交代码带入。日报建设与另一任务的负面巡查调度改动独立，本次只读取已有帖子、观测和处理审计。

## 已实现

报告中心新增「客户日报」，原综合日报/周报/月报保持独立。

- 默认昨天，可选择历史日期或今天实时版；生成新版本保留原版。
- 客户原表的两层表头与日行、MTD。监控按服务器首次入库的普通主帖计数；不计复采、评论、官方内容和博主资料。SDB只扣除非监控状态；已入库但AI预筛为无关的主帖仍按约定计数并提示。
- 负面总数与冷处理有系统数据；处理中、已处理严格留空。客户可在交付的飞书文档或Excel中补填。
- 发布时间落在统计截止前168小时，且互动合计≥200的有效负面全部入榜。保留原帖链接、分项/观测证据、数据时间及质量说明；昨日缺测不编造涨跌。
- 当日实际转入冷处理、生成时仍有效的负面链接，包含旧帖。解析单条和批量审计，重复保存不增加、撤销不列入。历史审计覆盖不全时明确说明。
- 页面、复制、打印、三张Excel工作表和飞书文档使用同一个不可变系统快照。客户修改飞书工作文档后，不反向改写系统，也不被后续任务覆盖。
- 页面可生成飞书文档、手动发群；管理员可配置每日自动发送前一天日报。已发正式版和同日定时任务会复用；明确选择更正版才新发后续版本。
- 文档独立于群消息去重，同一文档可向多个已授权目标群交付。卡片只含日期、版本、生成时间及文档入口，避免客户改稿后卡片数字过时。
- 独立发送任务每分钟处理持久化队列，与旧邮件报告及其AI生成任务分开。断线后只续做未完成阶段；未知远端结果停止自动重试，避免重复文档或重复群消息。
- 关闭自动规则会取消尚未开始的自动交付，保留明确的手动交付。正在执行的远端操作不能当作已撤回。服务重启依据已保存的时间补跑漏过日期，首次启用不追发历史。

## 数据和版本边界

报表日D、采集/互动截止C、生成复核时间G分别保存。历史补报采用G时有效的人工分类，不宣称重建了D日午夜的人工状态。首次入库按`records.created_at`，复采不改日期。

新增观测由服务器在补旧数值之前记录分项是否实测、评论防错是否沿用旧值，以及采集时间证据。只有完整实测指标与可信时间可以计算较昨日；完整历史入库记录可带明确质量说明入榜，不能冒充实测增幅。字段缺失不补成零。该改动无需更换扩展。

本次迁移执行时间是新冷处理审计覆盖起点；更早日期保留“历史记录不完整”说明。汇总冷处理与第三部分新增冷处理按不同集合计算，不强求数量一致。

系统保存版本不可变；飞书是客户可编辑的工作稿。修订会生成新系统版本和新文档，不覆盖客户手改正文。客户是业务数据所有者；飞书文件实际归属取决于写入应用所属组织。本次不自动转移文件所有权。

## 飞书上线配置与联调

目前没有创建真实飞书日报或向客户群发送消息。可复用现有「文档写入助手」；旧的首尔调研文档不是本功能写入目标。

1. 为服务端 API 和 scheduler 配置同一份 `CUSTOMER_DAILY_REPORT_ENCRYPTION_KEY`：32字节随机密钥的64位十六进制形式。它用于加密数据库中的应用密钥、Webhook和签名密钥；不能使用演示值，须随数据库备份妥善保管，不能直接换掉而不迁移已加密数据。未配置时页面仍可生成和导出，但不能保存飞书密钥。
2. 在后台「客户日报 → 飞书接入与自动发送」填写应用ID/密钥、专用日报目录token、文档组织域名、客户编辑者及目标群。目录必须符合飞书应用token创建文档的限制，不能只凭“我能在页面打开文件夹”推定应用可写。首次联调验证目录，不默认写根目录。
3. 核实应用的文档创建/读取/块写入、文档权限读取/协作者管理权限。使用应用机器人时还要有机器人发送消息能力及`im:message:send_as_bot`等实际所需权限，发布权限更新。已有接入成功不代表这些新增能力均已获批。
4. 优先保留现有客户群。由我方应用允许范围内的成员添加已开启外部共享的机器人；若采用群自定义机器人，配置该群Webhook和签名密钥。组织策略不允许时使用客户批准的应用/目录方案，不把换群当作绕过客户限制的方法。
5. 首次先点击「生成飞书文档」，用客户真实账号编辑正文与表格、保存，并验证可下载/复制留存。系统每次交付还会重新核查指定协作者和留存权限；不会自动设置全网可编辑。
6. 验证通过后勾选客户编辑验收，手动向明确的目标群发一份测试日报。确认目标、完整文档链接和客户修改保留后，再开启每日自动发送及时间。默认表单09:00只是待配置值，自动开关初始为关闭。

如果客户组织禁止编辑外部文档，必须获得客户组织批准的应用或文件空间接入；Excel可由客户下载编辑或导入，但这一步不属于全自动飞书交付。

应用凭据轮换会更新相同应用身份的待发任务认证，不改变其已确定的群、正文或编辑者。修改文档所属应用/客户编辑者时，新建日报版本，避免把旧文档当作已经获新授权。远端结果未知时应先核实文档/群结果，不通过反复点击或改状态盲目重发。
