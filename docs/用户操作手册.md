# StarVoice 星语 · 用户操作手册

> 适用范围：当前稳定版后台与配套 Extension。
>
> 目标读者：品牌运营、舆情、客服、销售、实施和租户管理员。
>
> 本手册讲“如何完成业务操作”，不要求读者理解代码。
>
> 核对日期：2026-07-30。版本号以实际安装包和页面显示为准。
>
> 后台地址：`https://voice.minilife.online/admin/`

---

## 1. StarVoice 能做什么

StarVoice 通过浏览器 Extension 在小红书、抖音等平台采集公开页面信息，再由云端完成保存、去重、AI 辅助分析、任务调度和业务处置。

主要能力包括：

- 关键词搜索采集；
- 单篇作品和评论采集；
- 博主主页和动态巡查；
- 官方账号评论巡查；
- 已知负面帖子的持续跟踪；
- 内容、评论和客资分诊；
- 工单跟进；
- 社交账号和 Agent 负载管理；
- 舆情趋势、数据看板和报告。

系统不会自动替代运营人员作出最终业务决定。AI 判断、风险提示和趋势分析用于辅助，误报、转工单、结案等关键操作仍应由有权限的人员确认。

## 2. 登录、租户与 Extension 激活

### 2.1 后台登录

1. 打开 `https://voice.minilife.online/admin/`。
2. 输入管理员分配的后台账号和密码。
3. 登录后确认右上角显示的用户身份。
4. 如果账号可访问多个租户，先选择正确租户。

后台账号用于访问 StarVoice 管理界面。它和 Extension 激活码、平台登录账号是三套不同身份：

| 身份 | 用途 |
|---|---|
| 后台账号 | 登录 StarVoice 后台、读取或修改业务数据 |
| Extension 激活码 | 把某个浏览器节点接入指定租户 |
| 小红书/抖音平台账号 | 访问平台页面并执行采集 |

不要用 Extension 激活码代替后台账号登录。

### 2.2 选择租户

页面右上角可以切换当前租户。切换后：

- 页面查询会读取该租户的数据；
- 新建任务会属于该租户；
- 只能向该租户下的 Agent 分配任务；
- 工单、社交账号、报告和配置也按租户隔离。

在创建任务、修改账号、删除节点或导出报告前，先检查当前租户。

租户切换器只是操作入口，真正的数据权限由服务端校验。即使浏览器保存了旧租户选择，也不会获得无权访问的数据。

### 2.3 安装 Extension

1. 获取最新客户交付包并解压。
2. 在 Chrome 打开 `chrome://extensions/`；Edge 打开 `edge://extensions/`。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择解压后的 Extension 根目录。
6. 建议将 StarVoice 固定到浏览器工具栏。
7. 打开侧栏，使用管理员提供的激活码完成绑定。

升级 Extension 时：

1. 替换为新的完整解压目录。
2. 回到扩展管理页。
3. 点击 StarVoice 的“重新加载”。
4. 重新打开平台页面和侧栏。
5. 在后台调度中心确认 Agent 版本和心跳更新。

### 2.4 登录平台账号

Extension 不代替小红书或抖音登录。使用前应：

1. 在同一浏览器打开目标平台。
2. 登录允许用于运营采集的平台账号。
3. 检查搜索页、作品页和账号页能否正常浏览。
4. 如出现登录失效、验证码或风险提示，先完成人工处理。

## 3. 桌面端与移动端入口

### 3.1 桌面端

桌面端是完整操作入口，推荐用于：

- 创建复杂任务；
- 多 Agent 编排；
- 查看任务详情和失败原因；
- 内容分诊和批量处理；
- 配置官方账号、社交账号和系统项；
- 查看完整看板和报告。

主要菜单：

| 菜单 | 用途 |
|---|---|
| 指挥中心 | 今日总览、风险和待办 |
| 舆情工作台 | 内容、评论、问题和误报；内容工单在内容分诊中就地处理 |
| 关注博主 | 关注账号、新动态、官方账号评论巡查 |
| 调度中心 | 新建、分配、继续、停止和查看任务 |
| 社交账号 | 平台账号身份、绑定和每日负载 |
| 销售客资 | 购买或咨询意向线索 |
| 分析与报告 | 数据看板和报告中心 |
| 舆情分析 | 专题和主题分析 |
| 数据底座 | 原始业务记录检索 |
| 平台管理 | 租户、用户、官方账号、激活码和设置 |

“调度中心”当前仍显示 Beta 标识。它已经承担实际任务调度，但新任务类型和平台页面变化仍需要持续验证。

### 3.2 移动端

在手机或窄屏设备打开同一后台地址，系统会进入移动布局。主要入口包括：

- 今日；
- 任务；
- 监控；
- 洞察；
- 更多。

移动端适合查看状态、处理重点内容和进行轻量操作。多 Agent 编排、大表格、复杂配置和问题诊断优先使用桌面端。

### 3.3 强制切换界面模式

如果浏览器记住了错误布局，可在页面提供的界面模式入口切换“自动、桌面或移动”。切换后页面会重新加载。

## 4. Agent 与执行节点

### 4.1 什么是 Agent

每一个安装并激活 StarVoice Extension 的浏览器实例都是独立 Agent。

例如同一台电脑同时打开：

- Chrome + StarVoice；
- Edge + StarVoice。

后台会看到两个 Agent，它们可以分别执行不同任务。Agent 不是整台电脑，也不是平台登录账号。

### 4.2 在线状态

Extension 定期向云端发送心跳。当前页面按最近心跳判断在线或离线：

- 绿色：近期有心跳；
- 灰色：超过页面规定时间未收到心跳。

“浏览器开着”不一定等于“Extension 在线”。还要确认：

- Extension 已加载；
- 激活码有效；
- 侧栏或后台脚本正常；
- 网络可访问 StarVoice；
- 浏览器没有休眠、锁屏中断或强制节能。

### 4.3 识别和命名 Agent

为了在多个设备间正确分配，建议使用可识别名称，例如：

- `Chrome · Windows-客服01`
- `Edge · macOS-运营Tony`
- `Chrome · Windows-木星`

不要只保留 `Chrome · macOS` 这类通用名称。

在调度中心：

1. 点击右侧 Agent。
2. 打开节点详情。
3. 点击“编辑节点”。
4. 修改节点名称和负责平台。
5. 保存。

设备内部 ID 主要用于技术排查，日常列表应优先使用业务名称。

### 4.4 删除旧节点

当浏览器已卸载、设备换租户或确定不会再上线时：

1. 确认节点没有正在执行的任务；
2. 确认没有仍需保留的排队任务；
3. 打开节点操作菜单；
4. 选择删除；
5. 阅读影响提示后确认。

删除节点不应删除已经产生的业务数据和历史任务。未完成任务应先停止、重新分配或移到历史。

## 5. 调度中心

### 5.1 页面结构

桌面端调度中心左侧是任务，右侧是 Agent。

任务分为：

- **执行中**：正在执行或排队的业务任务；
- **需处理**：失败、部分失败、中断或需要人工处理；
- **计划**：设备本地或云端可见的无人值守计划；
- **历史**：已经归档展示的任务。

右侧 Agent 展示：

- 名称；
- 在线状态；
- 最近心跳；
- 负责平台；
- 执行中数量；
- 排队数量。

### 5.2 新建任务

点击“新建任务”后按四步完成。

#### 第一步：任务类型

当前页面可能提供：

- 一次性关键词采集；
- 无人值守计划；
- 博主巡查；
- 负面帖子巡查；
- 官方账号评论巡查。

选择正确任务类型很重要。任务类型决定后续配置、页面入口和结果归属。

#### 第二步：执行方式

常见方式：

- **单 Agent**：整个任务交给一个浏览器节点；
- **多 Agent**：把关键词、帖子或其他工作项拆分给多个节点；
- **计划执行**：按指定日期或周期运行。

多 Agent 适合关键词多、帖子多或需要降低单账号负载的任务。

#### 第三步：选择节点

只选择：

- 当前租户下的 Agent；
- 平台能力匹配的 Agent；
- 在线或允许离线排队的 Agent；
- 当前负载合适的 Agent。

如果某 Agent 已绑定高风险或需要休息的平台账号，先到“社交账号”确认是否继续使用。

#### 第四步：任务配置

根据任务类型填写关键词、账号、帖子、数量、日期、增强、评论等设置。提交前检查页面顶部的任务摘要。

### 5.3 一次性关键词采集

典型配置：

- 平台；
- 关键词；
- 每个关键词最多采集条数；
- 排序；
- 发布时间；
- 内容形式或视频时长；
- 采集增强；
- AI 相关性筛选；
- 博主数据；
- 评论和评论上限；
- 是否跳过已增强内容。

创建后，系统会把关键词拆为工作项并分配。

### 5.4 无人值守计划

无人值守适合定时执行相同关键词或规则。计划页应显示：

- 平台；
- 关键词；
- 执行日期或周期；
- 执行时间；
- 轮次；
- 数量和筛选条件；
- 增强与评论设置；
- 下次和上次执行；
- 启用状态。

指定日期已经结束且没有后续排期时，应显示“已结束”或“无后续排期”，不应继续表现为未来计划。

计划本身是配置，不等于一次实际运行。每次触发后会产生独立任务记录。

### 5.5 多 Agent 编排

多 Agent 任务确认页会展示：

- 工作项总数；
- 选中 Agent 数；
- 每个 Agent 分到的工作项；
- 分配策略；
- 可人工调整的执行节点。

点击“确认并分配”后，应看到明确成功或失败反馈。没有反馈时不要重复点击，应先检查网络请求、任务是否已创建和“需处理”队列。

### 5.6 离线排队

如果允许离线排队：

- 任务会保留在云端；
- Agent 上线并发送心跳后领取；
- 后台应显示等待或排队，而不是假装正在执行；
- 长期不会再上线的 Agent 应重新分配。

### 5.7 继续任务

“继续”用于从云端保存的业务进度继续：

1. 在“需处理”或任务详情找到任务；
2. 查看已完成、失败和未完成工作项；
3. 点击“继续剩余任务”；
4. 确认继续模式；
5. 必要时重新选择 Agent。

继续应优先处理未完成或失败工作项，不应无条件从第一个关键词重头开始。部分平台步骤可能需要重新打开当前关键词页面，但已经成功结算的工作项不应重复写回。

### 5.8 停止任务

停止任务会向 Agent 下发停止指令：

1. 打开执行中任务；
2. 点击“停止任务”；
3. 确认；
4. 等待 Agent 回报停止；
5. 检查未完成工作项状态。

Agent 离线时，停止指令可能等待其重新上线。若设备已永久离线，管理员应结束或清理云端任务，而不是无限等待。

### 5.9 清理和移到历史

“需处理”中的失败或部分失败任务可以：

- 继续剩余任务；
- 重新分配；
- 保留结果；
- 移到历史；
- 清理已经结束的失败项。

清理任务列表不等于删除采集到的业务数据。

## 6. Extension 手动采集

Extension 会根据当前页面显示不同入口。

### 6.1 作品页

适合采集单篇作品：

1. 打开作品详情；
2. 打开 Extension；
3. 进入“作品页”；
4. 确认页面显示“已就绪”；
5. 如需评论，开启“附加采集评论”并设置上限；
6. 点击“采集作品数据”；
7. 完成后同步后台。

### 6.2 账号页

适合：

- 采集博主资料；
- 采集主页可见作品；
- 把账号加入关注博主；
- 为官方账号登记提供主页信息。

账号页增强不等于官方账号评论巡查。评论巡查仍应在调度中心创建任务，以便记录日期范围、Agent、作品数和评论上限。

### 6.3 搜索页

适合批量关键词采集：

1. 在平台完成关键词搜索；
2. 打开 Extension“搜索页”；
3. 选择排序、发布时间、内容形式等筛选；
4. 设置采集数量；
5. 决定是否启用采集增强；
6. 决定是否启用 AI 精准筛选；
7. 决定是否附加评论；
8. 开始采集。

抖音的一天内、一周内等平台筛选可以组合使用。设置较多时，建议确认最终筛选摘要后再执行，避免漏选或反复点击。

### 6.4 采集增强

列表页通常只能提供可见摘要。采集增强会逐条打开详情补充：

- 正文；
- 作者信息；
- 点赞、评论、收藏和转发；
- 图片或视频相关数据；
- 评论；
- 客资。

启用“跳过已增强内容”后，已经完整增强的内容不会重复打开详情，减少重复导航和账号负载。

### 6.5 AI 精准筛选

开启后，系统会判断候选作品是否与当前关键词和租户业务范围相关。

正常情况下，Extension 状态页应显示 AI 正在判断、跳过无关内容或继续采集。若页面一直没有 AI 进度：

- 检查是否真的开启 AI 精准筛选；
- 检查当前租户 AI 配置；
- 检查后台 AI 队列；
- 检查是否超时后按降级策略继续；
- 检查任务是否来自旧版本配置。

AI 无法判断、超时或服务异常时，系统应根据当前策略降级，不应静默把全部候选都当作无关。

### 6.6 任务状态页

云端任务执行时，Extension 会打开深色状态页，展示：

- 当前任务；
- 当前关键词或帖子；
- 整体进度；
- 当前步骤；
- 最近动态；
- 停止、隐藏或关闭操作。

任务结束后，Extension 应停止媒体播放并回到安全页面或搜索入口，避免详情页持续循环播放。

## 7. 关注博主

### 7.1 登记

最可靠的方式是在 Extension 的账号页打开真实主页后登记。

### 7.2 后台查看

进入“关注博主”：

- “关注的博主”管理关注资产；
- “博主新动态”查看最近发现；
- “官方账号评论巡查”只展示已确认的官方账号和评论巡查结果。

### 7.3 创建任务

关注博主页面不是任务执行台。要立即巡查或安排周期任务时，进入调度中心创建博主巡查任务。

---

## 8. 官方账号评论巡查

### 8.1 登记官方账号

可以从已关注博主中标记为官方账号，也可以由管理员在平台管理中登记精确身份。

应确认：

- 平台；
- 账号名称；
- 主页链接；
- 平台账号 ID；
- 别名；
- 归属品牌。

### 8.2 创建评论巡查

1. 打开调度中心；
2. 新建任务；
3. 选择“官方账号评论巡查”；
4. 选择 Agent；
5. 选择官方账号；
6. 设置最多作品数；
7. 设置每篇最多评论数；
8. 设置发布时间范围；
9. 创建并下发。

列表页不能可靠给出全部发布时间和评论，因此 Agent 会进入作品详情校验日期和读取评论。

### 8.3 查看结果

进入“关注博主 → 官方账号评论巡查”：

- 查看账号；
- 查看指定时间范围作品；
- 对比平台评论数和已入库样本数；
- 查看风险评论；
- 再次创建巡查。

平台页面显示的评论总数可能包含回复，也可能使用平台自己的统计口径；它不等于本次实际采集数。

## 9. 负面帖子巡查

### 9.1 创建

从内容分诊打开已知负面内容：

1. 核对原文链接；
2. 查看 AI 摘要和深度剖析；
3. 进入“舆情巡查”；
4. 创建任务；
5. 选择一个或多个 Agent；
6. 下发。

### 9.2 查看趋势

第一份快照只建立基线。第二次及以后才能计算互动增量和趋势。

重点查看：

- 最新互动；
- 历史快照；
- 评论和风险评论增加；
- 上升、平稳或回落；
- 内容是否已删除；
- 最后巡查时间。

### 9.3 内容已删除

当平台明确显示作品不存在、已删除或暂时无法访问时：

- 系统应标记“已删除或不可用”；
- 保留历史快照；
- 不把自动播放的下一条内容写回；
- 继续处理任务中的其他帖子。

## 10. 内容分诊

### 10.1 查看与筛选

进入“舆情工作台 → 内容分诊”，可以按以下条件筛选：

- 平台；
- 情感；
- 风险；
- 处置状态；
- 身份类型；
- 关键词或正文。

### 10.2 内容详情

详情可能包括：

- 原文和作者；
- 发布时间；
- 点赞、评论、收藏、转发；
- AI 摘要；
- 深度剖析；
- 评论；
- 官方回复；
- 采集快照；
- 舆情巡查；
- 处理记录。

负面内容可自动进行深度剖析；其他内容按需点击。

### 10.3 处置动作

可选择：

- 待处理；
- 负面流程；
- 官方已评；
- 无需操作；
- 已转工单；
- 误报；
- 归档。

“已转工单”在数据上是处理模式之一，操作界面会把它显示为独立的“工单分支”，与上方四种内容处理模式清楚分开。选择“转工单”后系统才会打开转单窗口并创建工单；系统不会因为内容被判断为负面就自动生成工单。

### 10.4 标记误报

如果 AI 或规则判断错误：

1. 点击“误报”；
2. 选择或填写正确判断；
3. 提交；
4. 平台管理员可在误判反馈中复查。

## 11. 评论分诊与销售客资

### 11.1 评论分诊

评论同步后会进入规则和 AI 处理。页面需要区分：

- 已抓取但等待 AI；
- 已完成分析；
- AI 超时或失败；
- 风险评论；
- 普通评论。

评论采集为 0 不一定是故障。先确认：

- 平台本身是否有评论；
- 是否开启附加评论；
- 评论上限是否大于 0；
- 评论区是否可见；
- 是否命中平台风控；
- 目标作品是否正确。

### 11.2 销售客资

AI 可从评论中识别购买、咨询、试驾、价格等意向。运营人员应人工确认后跟进。

客资数量是实际命中并保存的样本，不是平台全部评论数。

## 12. 内容分诊中的工单

### 12.1 转工单

内容可在“处理模式”菜单底部选择独立的“转工单”分支，评论仍在评论详情点击“转工单”：

1. 填写客户外部 Excel 中的工单号码（如有）；
2. 填写转单说明；
3. 选择处理人或队列；
4. 设置优先级；
5. 确认。

内容转单后不会离开内容分诊，处理模式更新为“已转工单”。没有号码时，原工单标记位置显示“补录工单号”；已有号码时直接显示号码。点击文字即可在当前列表行输入或修改，点击列表其他位置会自动保存。结案后号码只读。可按“已转工单”筛选，也可在搜索框直接搜索工单号码。

### 12.2 工单详情

工单详情应保留：

- 原内容；
- 作者和链接；
- 互动；
- 评论；
- AI 分析；
- 巡查快照和趋势；
- 转单说明；
- 处理记录。

内容转工单后，后续负面巡查的采集记录仍会继续显示在工单来源详情中。

### 12.3 记录进展和结案

处理人可在内容详情的“处理记录”中记录沟通、私信、回复、转交等工单进展；普通内容备注、转单、工单进展和结案会按时间显示在同一条处理时间线上。

处理完成后，直接在内容详情点击“结案”。确认后工单结案，内容同时移入“已归档”，不再进入独立的工单闭环页面。结案不会删除原内容、评论、巡查历史或处理记录。如需再次处理，先在“已归档”中取消归档，再创建新工单；历史结案记录会保留。

本次内容分诊改造不新增独立“客服工单”菜单；评论转单继续沿用原有流程。

## 13. 社交账号

进入“社交账号”查看每个用于平台操作的登录账号。

### 13.1 账号资料

可查看或维护：

- 平台；
- 账号名称；
- 平台账号 ID；
- 注册手机号或备注；
- 当前 Agent；
- 绑定方式；
- 状态。

### 13.2 绑定

- 自动识别：Extension 读取当前登录身份后自动更新；
- 手动指定：管理员选择账号与 Agent。

手动指定时，只应绑定勾选的 Agent。保存后未勾选的 Agent 不应被自动加回。

### 13.3 每日负载

页面展示：

- 搜索次数；
- 增强次数；
- 采集运行次数；
- 采集条数；
- 失败事件；
- 限额。

这些数据用于判断继续、休息、重新登录或停用，不代表平台官方公布的安全额度。

## 15. 常见异常

### 15.1 Agent 显示离线

检查：

1. 浏览器是否仍在运行；
2. Extension 是否启用；
3. 激活码是否属于当前租户；
4. 网络是否正常；
5. 是否锁屏、休眠或强制节能；
6. 扩展管理页是否有错误。

### 15.2 浏览器开着但任务没有收到

检查：

- 后台选择的 Agent 是否就是当前浏览器；
- Agent 名称是否清楚；
- 当前租户是否一致；
- Agent 是否已有执行中或排队任务；
- Extension 是否为最新版本；
- 任务是否仍在云端排队；
- 平台能力是否匹配。

### 15.3 任务卡在旧任务后面

打开 Extension 本地任务中心：

- 查看旧任务是否已结束但仍占用；
- 保留有用结果；
- 将结束任务移到历史或清理；
- 再等待新任务领取。

### 15.4 继续后又从前一个关键词开始

先查看工作项状态。页面导航步骤可能重新打开当前关键词，但已经成功的工作项不应重复写入。若整体进度倒退或重复保存，记录任务 ID、Agent 和时间，交给技术人员排查断点。

### 15.5 锁屏后中断

浏览器自动化依赖页面持续运行。锁屏、休眠、关闭浏览器或系统回收后台页面都可能中断。使用云端“继续剩余任务”，必要时换到在线 Agent。

### 15.6 抖音“服务出现异常”

这不一定是账号被封，也可能是某个搜索结果暂时为空或页面服务异常。系统应记录当前关键词并继续下一个工作项；如果连续出现安全验证或风控，则停止自动操作并提示人工介入。

### 15.7 抖音验证码或安全提示

不要自动绕过。应：

1. 暂停当前 Agent；
2. 发出人工介入提示；
3. 人工完成验证或选择结束；
4. 未完成工作项可重新分配给空闲 Agent。

### 15.8 抖音跳到 AI 抖音

可能是页面控件位置或标签变化导致误点。立即停止任务，记录目标作品、实际页面和时间。更新 Extension 前不要继续批量操作。

### 15.9 目标作品不匹配

系统会阻止云端写回，避免把错误作品覆盖到目标记录。常见原因：

- 页面自动播放到下一条；
- 详情页仍在加载；
- 目标链接重定向；
- 平台作品 ID 解析变化。

重试时先确认浏览器地址和页面作品与任务目标一致。

### 15.10 作品已删除或不可访问

平台明确显示不存在时应记为“已删除或不可用”，不是普通失败。历史快照保留，不再继续采集该作品。

### 15.11 评论数和实际采集数不同

平台显示数可能包含回复或使用平台口径；StarVoice 显示的评论页签数量是实际入库样本。查看本次读取数、入库数和任务评论上限。

### 15.12 官方账号评论巡查失败

检查：

- 官方账号主页链接；
- 账号身份是否登记正确；
- 日期范围；
- 候选作品是否有精确发布时间；
- Agent 平台能力；
- 详情页和评论区是否可访问；
- Extension 日志中的具体失败原因。

### 15.13 AI 没有介入

检查：

- 任务是否开启 AI；
- 当前租户是否配置可用模型和额度；
- AI 队列是否拥堵；
- 是否达到超时；
- 页面是否显示降级继续；
- 是否使用旧任务配置。

不要只根据页面速度判断 AI 是否运行，应查看任务动态和后台处理状态。

### 15.14 AI 判断明显错误

点击“误报”或“编辑判断”，保存正确结果。提供标题、正文、关键词和正确分类，帮助管理员更新规则和提示词。

### 15.15 账号识别不出来

检查平台是否登录、页面是否为账号页、Extension 是否最新。自动识别不能保证覆盖所有页面变体，可在“社交账号”手动补充和绑定。

### 15.16 任务失败一直在“需处理”

已结束的失败或部分失败任务可以移到历史或使用“清理已结束失败项”。需要人工介入或仍可能继续的任务会保留。

### 15.17 更新 Extension 后没生效

1. 在扩展管理页点击重新加载；
2. 刷新平台页；
3. 重新打开侧栏；
4. 确认后台 Agent 版本和心跳；
5. 新建一个小任务验证。

## 16. 日常操作建议

### 每天开始前

- [ ] 确认当前租户；
- [ ] 确认 Agent 在线和名称；
- [ ] 确认平台账号登录；
- [ ] 查看社交账号负载和风险；
- [ ] 清理已经结束的失败任务；
- [ ] 查看是否有验证码或人工介入。

### 创建任务前

- [ ] 任务类型正确；
- [ ] 目标关键词、账号或帖子正确；
- [ ] Agent 平台能力匹配；
- [ ] 日期范围正确；
- [ ] 数量上限合理；
- [ ] 是否需要增强、AI 和评论；
- [ ] 多 Agent 分配符合预期。

### 任务结束后

- [ ] 查看成功、失败、跳过和不可用工作项；
- [ ] 检查评论实际入库数；
- [ ] 检查是否串到错误作品；
- [ ] 检查媒体已停止播放；
- [ ] 对负面内容建立或更新巡查；
- [ ] 需要人工跟进时明确转工单；
- [ ] 结束任务移入历史。

## 17. 当前 Beta、测试中与未实现能力

### Beta 或需持续验证

- 调度中心整体；
- 多 Agent 失败转移；
- 抖音风控、验证码、自动播放和页面结构变化；
- 小红书与抖音删除页的全部变体；
- 社交账号自动识别完整率；
- 移动端复杂配置；
- AI 高峰期处理速度；
- 报告邮件发送配置。

### 当前不应承诺

- 浏览器关闭后仍能直接采集平台页面；
- 正在执行的浏览器会话无缝迁移；
- 自动解决验证码或绕过风控；
- AI 判断完全准确；
- 仅靠账号名称自动确认官方身份；
- 负面内容自动转工单；
- 一份快照直接得出真实趋势；
- 平台显示评论总数全部采集入库；
- 平台改版后无需更新 Extension；
- 移动端拥有全部桌面配置体验。

### 暂未开放

导航中标记为“Coming Soon”或仅展示占位页的功能尚未正式开放，例如内容创意工作区中的“内容复盘”。不要将占位入口作为可交付能力承诺给客户。

## 18. 需要技术支持时提供什么

为了快速定位，请提供：

- 当前租户；
- Agent 名称；
- 浏览器和系统；
- Extension 版本；
- 平台；
- 任务编号；
- 发生时间；
- 目标关键词、账号或帖子；
- 后台任务详情截图；

不要发送真实 API Key、激活码、Agent Token、密码或完整手机号。
