# Extension 0.4.25 · 创意采样与进度布局修复

分支：`codex/extension-ui-refresh`。发布授权：用户明确要求“提交部署”。

## 发布边界

- 新版 UI 修复创意采样期间误退出、共用进度遮挡底部操作，并压平监控列表；隐藏微博入口，保留历史记录和经典回退。
- Extension 运行代码仅 `sidebar/ui-next.js`、`sidebar/ui-next.css` 改动。manifest 仅更新版本和删除介绍中的微博，权限与入口不变。
- 后端只更新 `server/routes/update-manifest.js`、`server/public/about.html`、`server/services/ops-control.js` 中的版本常量及公告。无业务 API、数据库、调度、采集协议或安全保护变更。
- 经典界面仍默认，旧节点最低支持版本维持 0.3.51，不强制升级。保留 0.4.24 安装包。
- 发布只短暂重启 API；不重启 scheduler、ai-media、Android Runner 或浏览器扩展，不派发或停止任务。
