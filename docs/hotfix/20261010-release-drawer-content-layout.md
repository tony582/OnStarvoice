# 详情抽屉「内容」页签重排：原帖在上、AI 在下（2026-10-10）

分支：`feat/drawer-content-layout-20261010`，提交 `7835b72`（基于 `main` `c5e9f3c`）。**已于 2026-10-10 14:28:20 发布到生产，只换后台静态文件，服务进程没有重启。**

## 为什么改

原来的「内容」页签把原帖和 AI 产出混在一列，顺序是：正文 → AI 摘要 → 判断依据 → 深度剖析 → 视频 → 逐字稿（里面还套着逐字稿的 AI 分析）→ 图片。标题有四种样式。要看视频和图片，得先翻过整段分析。用户的要求是：图片、视频、正文、视频文案、图片文字放上面，基本不用点「原文」；AI 分析放下面；排版要有层次。

## 现在的结构（`RecordContentTab`）

- **原帖内容**
  - 视频帖：视频 → 正文 → 视频逐字稿 → 封面。逐字稿超过 240 字时折叠成 6 行，可「展开全文」。封面保留在图集里是为了能提取封面文字，所以放在最后，标题标成「封面」。
  - 图文帖：图片（每张可「提取文字」）→ 正文。
- **AI 分析**：摘要 → 深度剖析 → 视频内容分析（原来套在逐字稿里的那块 AI 分析）→ 判断依据。
- 两组各有一个组标题（图标 + 分隔线），组内小节标题统一用 13px 半粗体。
- 逐字稿原文和它的 AI 分析分属两组，共用一份状态（`useRecordTranscript`），只拉取一次。顺带去掉了这部分代码里的 `any`，后台 lint 基线从 261 降到 254。
- 图集缩略图从正方形改成 3:4，小红书竖图上下不再被裁掉。

新增契约测试 `tests/record-drawer-content-layout-contract.test.mjs`，锁定两组的顺序和归属。
