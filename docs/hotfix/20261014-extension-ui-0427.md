# Extension 0.4.27 · 紧凑顶栏与流内采集按钮

分支：`codex/extension-ui-refresh`。用户授权：提交部署，继续独立分支，不动采集逻辑。

## 发布范围

- 新版移除与浏览器侧栏标题重复的 logo 和名称，顶栏压缩为 44px，左侧运行状态、右侧原平台切换控件。
- 笔记页、博主页、搜索页的原采集按钮回到表单末尾、采集内容之前，随页面滚动，不再固定占用底部空间。
- 搜索页保留批量采集入口；菜单向下展开，打开时按需滚动显示。底部四项导航保留，移除旧按钮条的空白占位。
- 仅修改 `sidebar/ui-next.js` 与 `sidebar/ui-next.css` 的展示行为；未修改采集引擎、同步、分析、调度、后台通信或业务参数，无新增轮询。
- manifest 仅递增版本。服务器只更新下载包、公告及版本基准，不修改 API 业务逻辑、数据库或调度。

## 兼容与操作边界

- 经典界面仍为默认，已有新版偏好保留，可切回经典。最低支持版本继续为 0.3.51，不强制旧节点升级。
- 不重载任何浏览器扩展，不派发、停止或迁移任务。仅短暂重启 API，保持 scheduler、ai-media 及其它服务不变。
- 保留 0.4.26 下载和服务器元数据备份。升级应在节点空闲、结果保存后，在原目录更新并重载；不要并装第二份扩展。
