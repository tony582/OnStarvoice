# 0.4.14 合并 hotfix 发布单

本地候选，尚未部署或重载生产 Extension。基线为 `c06c7cb5d9eb93ff9ae5f795645999755543bfb8`，已完整纳入关联任务的 Android 候选 `7dd1fc0`。本轮不改动 AI 相关性判定策略。

## 发布内容

- 新增「关键词采集 → 平均下发手动采集」：选择节点后预览均分结果，将关键词和完整设置下发到 Extension 的「搜索页 → 手动采集 → 批量多个关键词」，调用该按钮的原执行函数。
- 包含帖子上限、点赞下限、排序、发布时间、内容类型、搜索范围、位置距离、抖音视频时长、当天延迟启动，以及增强、自动同步、AI、作者指标、低粉筛选、评论数量、评论客资筛选、跳过已增强内容。允许明确沿用目标设备的本地增强设置或帖子上限。
- 每个节点独立执行一次，不创建无人值守计划、不自动转交或重新启动。后台保留任务进度和结果；执行页关闭或刷新会标记需核对。下发重试沿用原请求编号，已确认节点不会重复下发。
- 旧任务未确认本地停稳时，禁止同一节点领取新执行指令；普通已经结束的失败不会永久占用节点。
- 最后同步失败、有剩余队列或未完成排空时，不能把整个批次报告为完整成功。
- Android 单手机试点、浏览器补采、停稳和恢复、作者与表情文本、补采关页，沿用 [Android 发布单](20260923-android-pilot-release.md) 的试点边界；本合并版统一版本号为 0.4.14。

## 产物与发布

候选产物位于 `output/release-0.4.14/`：Extension zip、服务端与 Admin 白名单增量包、独立 Android Runner 包、源码补丁，以及含逐文件 SHA-256 的 `release-manifest.json`。

1. 部署前复核生产文件仍与基线匹配，取得应用回滚副本和有效数据库备份。不能直接运行旧全量同步部署脚本。
2. 服务端只覆盖发布清单中的文件；保留生产环境配置、依赖、上传与旧下载包。Admin 先放入新静态资源，再切换 index。
3. Android 仅应用新增迁移 086、087、088、089；先核对迁移登记，不重复执行既有迁移或回填。租户开关默认保持原值，开通仍按单手机试点范围进行。
4. 服务端切换、健康检查通过后再更新 Extension。正在采集的节点先确认结束或停稳，再重载；旧节点不支持手动下发时，页面会提示先升级，不把它回退成旧无人值守任务。
5. 手动下发先用一个空闲节点验收：设置与本地控件一致、单次启动、AI/增强/同步回执可核对；然后再使用全部 8 个节点。当前旧任务的失败和待同步记录须保留，不以升级自动重跑。
6. Android 保留指定镜像账号、单手机与单补采节点的边界，初次仅 1 个关键词。真机验收与长时间稳定性单独记录。

## 回滚

先停止新增下发，并确认在途手动、无人值守及手机任务停稳。恢复服务端/Admin 回滚目录和原 Extension；保留新增账本和已采集数据，不执行 DROP 或整库覆盖。原主工作区的生产 `extension-build/` 本轮保持不变。
