## 问题与修复

作品 `7688168579418098019` 的发布者是 Change，正文只是 @ 上海安吉星信息服务有限公司。旧详情提取器扩大到整个 document 搜索用户链接，并给 @ 开头的链接加分，可能把正文提及或评论者的账号 ID 作为作者提交。服务端随后按这个错误 ID 命中官方账号排除。搜索列表也有从整卡正文提取 @ 名称、再任取用户链接的同类兜底。

详情和搜索列表现在复用作者身份提取：只读取当前作品详情或搜索卡片内的发布者区域，作者名与账号 ID、主页 URL 从同一区域取得；排除正文提及、评论、推荐和隐藏节点。缺少可靠主页链接时保留已确认的作者名，不借用其他账号的 ID。官方发布者的昵称即使以 @ 开头，仍正常匹配官方账号规则。

本次没有调整官方账号排除配置、服务端分类规则、AI 筛选规则或数据库结构。

## 每个账号都搜索所选关键词

在调度中心新建关键词任务或无人值守计划，使用弹性节点池、选择抖音后，可在“关键词覆盖方式”选择“每个所选节点都采集”。默认仍为原来的分工采集。系统使用每个浏览器节点当前登录的抖音账号，不识别或核验不同节点是否登录了同一个账号；选择节点时需确认账号不同。

每个关键词与每个所选节点组成独立工作项。例如 6 个词、6 个节点生成 36 项，完成一个节点不会结算其他节点的覆盖。每台节点逐项执行，离线、失败或等待恢复的项保留原目标节点，不改派到另一个账号。继续使用现有帖子入库去重，不把多个账号看到的同一个视频当成多条新内容。每批最多 1000 个工作项。

使用已有 `pinnedAgentId` 领取约束，不更改调度器的并发、安全验证或失败重试规则。创建、预览和下发校验完整的关键词/节点组合；重复提交保持幂等。计划保存和编辑按组合保留工作项身份，下一轮生成时保留目标节点。编辑已发布计划只影响未来批次。附带的负面巡查仍使用原来的逐帖队列，不按节点复制。

快捷词清单仅供创建/编辑时勾选，不自动修改已有计划：

- 本次重点：别克壁纸、凯迪拉克壁纸、安吉星壁纸、安吉星车机壁纸、月兔栖梦、檐下秋意。
- 建议补搜：别克车机壁纸、凯迪拉克车机壁纸、君越壁纸、君越车机壁纸、昂科威壁纸、昂科威PLUS壁纸。车型词来自用户提供的实际帖子用词；组合词用于补充不同表述，尚未测量各词的新增命中率。
- 不把“壁纸”“秋天”“兔子”等泛词直接加入整池轮询，以免大量引入无关结果。多账号与扩词能增加覆盖机会，不能证明已找齐平台上的全部帖子。
