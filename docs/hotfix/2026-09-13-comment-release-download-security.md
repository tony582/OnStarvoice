## 下载目录规则

- `/opt/onstarvoice/public-downloads`：仅放正式的 `StarVoice-extension-v版本-日期.zip`。
- `/opt/onstarvoice-private/releases`：内部代码包、部署脚本、发布清单、CI 结果、回滚材料；父目录权限 0700。
- 数据库备份放在上述非公开区域，文件权限 0600。
- 应用不再将整个 `releases` 目录映射到 `/downloads`；Nginx 同时使用 `deploy/nginx/public-downloads.conf` 约束公开入口。
- 发布过程不得向 `public-downloads` 或历史 `releases` 路径写入任何内部材料。先校验插件 ZIP、版本、内容及 SHA-256，再提供下载。
