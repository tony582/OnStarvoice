# StarVoice 0.4.2 AI 跳过热修说明

日期：2026-08-31

## 变更

- 服务端返回有效的 `skip_full_capture` 后，Extension 不再重复套用固定 `0.97` 阈值；服务端判定为明确无关的 `0.95` 结果会真正进入跳过集合。
- 真正跳过发生在详情页、评论和博主增强之前；占位标题、保护信号、无效响应和模型异常仍保持安全放行或延迟增强。
- 审计字段区分服务端模型建议与 Extension 实际动作，侧边栏不再显示“已跳过增强”却仍继续采集。
- 后台继续按服务端相关性结论过滤无关内容，避免旧客户端误采结果进入普通业务视图。
