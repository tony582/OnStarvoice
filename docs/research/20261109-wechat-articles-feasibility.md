## 结论与本轮边界

**可行，但需要新增文章适配器，不能直接把文章链接交给现有视频号采集器。** 在现有手机上，已从「搜一搜 → 文章」打开三篇真实文章，读到标题、公众号、显示到分钟的发布时间、正文或长图片中的文字、可见互动指标；两篇的文章末尾留言可读，第三篇已到正文底部但没有留言入口。

本轮是有边界的真机调研和本地取证，不是自动采集功能完成：尚未实现全文无遗漏拼接、文章去重、批量调度、入库、负面巡查或文章转发。没有把调研样本写入生产，没有发布新代码。原图文件、头像文件和嵌入媒体均未采集。

最终入口按用户选择固定为 **微信「搜一搜 → 文章」**。中途查看过「看一看」，不将它的搜索入口作为实现依赖，也不据此推断 iOS 或将来 Android 的功能变化。

## 已实测的入口与筛选

路径：发现 → 搜一搜 → 搜索“安吉星” → 横向找到并选择“文章”。文章分类需读回标题和下划线状态，不能仅依赖坐标；本次分类栏发生过布局变化。

文章列表可见：标题、摘要、缩略图、公众号、相对发布时间；部分卡片有阅读量，部分没有。没有阅读量不等于阅读量为零。

文章筛选可见「不限／最新／最热／已关注」及「互动」菜单。本轮实际选择并验证了“最新”：结果前几条依次为 16 小时前、3 天前、5 天前、7 天前。仅观察了最热、已关注及互动选项，未把它们声明为完成自动筛选验收。

“互动”弹层有“看过”和多个图标按钮；尚未验证全部图标的准确语义。文章页没有看到视频号的“时长”筛选，不能照搬该字段。发布时间窗口仍应按文章显示时间复核；本轮没找到文章分类内的独立发布时间范围控件，不将此前其它分类的筛选误算为文章功能。

### 留言状态必须分别表示

1. **有留言**：正文结束后读取公开可见留言，保留作者、地区、日期、正文、赞和父子关系；未显示的字段保持缺失。
2. **关注后才可发表**：只是发表限制，已有留言照常采。本次图文样本已实测。
3. **没有留言入口**：在已看到正文结束和阅读行后仍无入口，记录 `unavailable / no_visible_comment_entry`，正常保留文章。不能只因找不到入口就说作者明确关闭，更不能编造 0。
4. **页面明确关闭留言**：保留提示原文；如果旧留言还可见，仍采旧留言。这个明确提示分支本轮未遇到，后续需补样本。
5. **明确暂无留言**、**加载失败／未到末尾**、**达到采集上限**、**计划未开启采评论**：各自独立，不能合并成“关闭”。本轮未覆盖所有状态。

留言的发表权限、当前可见范围和本次读取结果应分成字段，而不是一个 `disabled` 值同时代表这些含义。

## 原文链接与正文来源

文章复制路径已实测三次：右上角“…” → **最下面功能栏向左滑** → “复制链接” → 读取手机剪贴板，得到 `https://mp.weixin.qq.com/s/<标识>`。首行是转发／外部打开，不要在首行寻找复制链接。过快滑动可能把复制按钮滑出屏幕，应重新识字定位再点击。

两条不同文章短链各进行一次普通、无登录信息的 HTTPS GET，均跳转到 `/mp/wappoc_appmsgcaptcha`，页面提示“环境异常／完成验证／继续访问”。虽然 HTTP 是 200，但没有文章正文容器，不能误当成功。遇验证已停止，没有绕过验证或导出微信登录信息。

这是两个样本的结果，不能概括成所有文章都不能在电脑端读取；也不能假定换成浏览器一定能读到全文。本轮没有建立可依赖的公开正文读取通道。

因此第一版应以手机可见内容为保底来源：

- 文章标题、作者、时间、阅读和互动数：截图与 OCR，分别保存原始标签、解析值和精度。
- 正文：有重叠的有界逐屏读取，剔除固定导航、广告、推荐卡、留言区；验证相邻屏拼接与真正的正文终点。超时、缺屏、OCR 失败标 `partial`。
- 图片内文字：单独标注 OCR 来源，不伪装为原生正文；已有截图不代表保存了原图。原图、嵌入视频／音频和永久回放尚未验证。
- 文章身份：保留原始分享短链，先支持相同规范短链去重；同文多次复制、其它入口链接及 `__biz/mid/idx` 映射仍需验证。不可沿用视频号“作者＋秒级发布时间”作文章唯一 ID。

## 实施建议与未完成验收

按 [契约审查](20261109-wechat-articles-contract.md) 新增独立 `wechat_articles` 适配器及能力标识，复用现有手机互斥、任务调度、租约、停止恢复、持久事件、回执、租户隔离、AI 相关性、分诊和分析。关闭／未开放留言不影响正文采集成功；正文与留言的完整性分别保存。

进入上线前至少补齐：

- 长文全文拼接与长图片 OCR 的准确性、原图／封面保存边界，以及超过现有 20,000 字上限的处理。
- 明确关闭、明确空留言、精选留言、展开回复、只允许关注后发表及文章失效等样本。
- 公众号署名差异、分钟／日期精度、缩略互动数、动态底栏布局和缺失指标。
- 同文跨关键词、多次复制链接和不同原文 URL 的稳定去重。
- 实际新关键词输入、完整返回恢复、筛选读回、单任务停止与批量连续运行。
- 服务端／数据库／后台新增平台及状态展示；负面巡查找回原文、文章“发到微信”独立验收。
- 隔离 PostgreSQL 全路径测试与新旧采集器能力门槛；本轮未执行这些功能测试，因为没有实现产品代码。

**推荐先完成本地文章采集原型，再接服务端；目前证据足以进入实现，不足以宣称可上线或与视频号全路径等价。**
