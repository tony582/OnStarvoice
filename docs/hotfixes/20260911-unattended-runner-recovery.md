## 已确认的问题与改动

### 运行页刷新与启动失败

已核对的 `unattended_begin_fence_changed` 现场中，启动之前记录的平台页编号为 1146179886，启动期间被运行页心跳改成 1146179994，其他任务与尝试身份相同。

后台现保留已经绑定具体采集任务的无人值守源页面身份。同一任务、同一次尝试的运行页重复打开时只激活已有页面，不重新导航。收尾在发送停止及刷新前确认目标是否为扩展页面，避免对运行页反复执行刷新。

旧的错误绑定仅允许从同一任务、同一次尝试的 Debug / 标签页分组记录找回平台源页面。找不到可靠来源时保留锁，停止反复收尾，不把“无法确认停止”伪装成已停止。手动采集和未绑定采集任务的心跳规则不变，微博的既有心跳机制保留。

### 部分完成与继续派发

抖音两步搜索必须两步各自有最新的完成记录，才能把关键词算作完成。第一步已完成、第二步启动失败时保留第一步，下个节点从第二步继续。重复轮次按每轮最新结果判断，防止旧成功覆盖新失败。

自动恢复仍受次数、安全限制、用户关闭自动重试和手动取消约束。后台展示区分待恢复、已派发、执行中和需要核实；缺少实际执行记录时不再借用上次成功记录。运行侧的结束进度按真正完成的步骤计算，启动失败的 0/2 不再显示 100%。

### 安吉星搜索结果中不可查看的帖子

用户指定记录：`Vo83——你会不会为车联网买单`，作者 AutoBiBiBi，小红书作品 `6aa1e9900000000012027610`。

只读现场核对：

- 记录 ID：`401f1c77-ba3b-4dd0-97c5-aea611da0be7`；后台仍为 `available`，详情增强 `failed / NOTE_CAPTURE_FAILED`。
- 父任务：`11dbc27c-39dd-4a70-ae12-0665f12d86b5`；关键词工作项：`447021c8-928d-4e5b-93eb-0a6a5b630e95`。
- 9 月 11 日核对时尝试已达 16 次，父任务和工作项均为用户取消。没有重新打开、重试或派发这条任务。
- 浏览器只读打开该作品后跳到对应作品的 404 页面，展示“当前不可查看 / App 扫码查看”页面。这能证明当时 Web 端不可访问，不能证明作者删除。

根因：原有不可查看页识别只接在定向作品采集，关键词搜索后的详情增强未接入，普通增强失败又被上层关键词恢复重复派发。

修复后的完整路径：

1. 小红书详情增强在导航完成、增强前及失败后检查目标页面。404 重定向仍校验原作品 ID；双工作页的失败使用实际失败页身份。
2. 明确的删除文案记录为 `deleted`。QR 限制或可见的“该内容暂时无法查看”平台提示记录为 `page_unavailable`，自动跳过有效期为 24 小时。普通文章引用这些文案、登录、安全验证、网络错误和其他作品页面不能直接产生不可查看结果。
3. 结果作为单帖业务跳过结算（`ok / skipped / post_unavailable`），清除该条增强错误和自动重试次数，保留搜索列表数据。其他帖子照常继续，真实临时故障仍按原规则重试。
4. 同步将结构化的作品身份、观察时间、状态与证据保存到现有可访问性字段。无需数据库迁移。已有完整正文和客户处理字段保留，普通失败或列表重传不能清除可访问性记录。
5. `/api/sync/captured` 按租户、平台和作品返回有效的不可查看结果。另一设备在创建详情工作页之前即跳过该作品。迟到的旧观察不能覆盖较新的状态；较新的成功详情可恢复可访问性。
6. 显式关闭“跳过已采过”仍允许人工重查。修复不会自动根据旧 `NOTE_CAPTURE_FAILED` 把历史内容批量改成删帖，也不会恢复已取消任务。

## 历史步骤修复工具

`server/scripts/repair-incomplete-search-passes.js` 用于审查被错误算作完成的分步任务；它不用于修复已取消的安吉星任务。

默认只预览，必须指定租户和父任务，可再限定工作项。范围最多 50 个工作项。应用时必须带预览结果的 fingerprint；事务内重新检查范围、当前尝试、任务状态、活动命令和恢复次数，并写审计记录。手动取消、停止、隐藏、实际已完成和不可恢复条目均不重新开启。

在 `server` 目录中预览：

```sh
node scripts/repair-incomplete-search-passes.js --tenant UUID --parent UUID --items UUID
```

`--apply --fingerprint SHA256` 才会应用审查过的结果。工具自身不派发工作；修复后正常的节点领取流程才可能继续。当前没有对生产执行此工具。
